# Explorando a Sintaxe: Estruturas Condicionais em Portugol

Exercícios de lógica de programação focados no uso de estruturas condicionais, desenvolvidos para prática acadêmica utilizando Portugol.

## Exercícios

1. **Validador de Maioridade**  
Verifica se o usuário possui 18 anos ou mais com base no ano de nascimento.

2. **Radar de Velocidade**  
Calcula multa para veículos que ultrapassarem o limite de 80 km/h.

3. **Sistema de Aprovação Escolar**  
Calcula a média de duas notas e determina se o aluno está aprovado, em recuperação ou reprovado.

4. **Par ou Ímpar**  
Identifica se um número informado é par ou ímpar utilizando o operador de resto da divisão.

5. **Analisador de Triângulos**  
Verifica se três valores podem formar um triângulo e classifica como equilátero, isósceles ou escaleno.

## Tecnologias

- Portugol
- Portugol Studio
- Git / GitHub
